# SilentSOS — Personalised Emergency Communication Assistant

## Overview
SilentSOS is an accessibility-focused web application designed to help individuals with speech disabilities or other communication difficulties express their immediate needs during emergencies and stressful situations.

## Problem
Communication barriers can make it difficult to explain specific needs quickly during stressful situations. Conventional emergency solutions may rely on speech, typing, or assistance from others.

## Proposed Solution
SilentSOS aims to provide a simple, three-tap communication workflow that generates personalised help messages through an accessible visual interface.

## Planned Features
- Three-tap personalised help-message generation
- Full-screen communication cards
- Tamil and English message support
- Personal communication preferences
- Large-text and high-contrast modes
- Offline access to predefined messages

## Technology Stack
HTML, CSS and JavaScript.

## Project Status
Initial prototype development.


## Disclaimer
SilentSOS is a proposed communication aid, not an emergency dispatch service. It does not automatically contact emergency services.
